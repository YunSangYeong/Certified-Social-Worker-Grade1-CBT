# Certified-Social-Worker-Grade1-CBT
사회복지사 1급

사회복지사 1급 필기 CBT 학습 앱. React·TypeScript·Vite 기반이며 로그인·백엔드·유료 API 없이 동작한다.

**현재 한계: 내부 검토 자체 제작 200문항으로 목표 1,000문항보다 800문항 부족하다. 공식 규칙 원문 대조와 외부 전문가 검수도 미완료다. 1,000문항 표준 충족 또는 공식 시험 완전 재현을 주장하지 않는다.**

## 적용한 표준

- 최신 원본 `YunSangYeong/electrician-cbt` main: `76b990b8720adfa85c22a0a8f699b17094aa357b`.
- CBT 표준 **v1.4.0** 전체 폴더를 `.agents/skills/cbt-site-standard/`에 복사하고 루트 `AGENTS.md`에 연결했다. 대상 저장소에는 기존 AGENTS.md가 없었다.
- 앱 기준 `b9a682ccff1b460334b78d5bfad9375b7ec4fbb6`의 실제 App·CSS·model·설정·테스트·workflow 구조를 재사용했다. 읽기용 원본 저장소에 수정·푸시·재배포하지 않았다.
- 소스의 MIT 저작권 고지를 LICENSE에 보존했다. 전기 문제 데이터·원고·개인 학습 기록은 가져오지 않았다.

## 기능

- 대시보드, 실전 모의시험, 랜덤 문제풀이, 오답노트, 북마크, 영역별 통계, 문제은행 관리.
- 두 모드 모두 답안 선택/채점 후 Space로 다음 문제 이동. 포커스·반복키·수정키·IME·입력·메뉴·대화상자 보호. 교시 마지막 문제에서 자동 제출하지 않는다.
- 3교시의 절대 종료 시각과 답안 즉시 저장. 새로고침/비활성화에도 시간이 연장되지 않는다. 교시 종료 시 해당 답안 잠금, 휴식 후 다음 교시를 직접 시작한다. 마지막 교시 제출 후 전체 채점과 해설 제공.
- 전체/영역별 랜덤 순회, 즉시 채점 1회, 연속 정답, 오답 재학습 정답 시 해제, 북마크, 최근 시험.
- JSON/CSV 가져오기·양식·검색·상태 필터·페이지 목록·중복 제거·검증 대기·근거 기록 후 로컬 승인·문항 내보내기.
- 학습 기준·자료 연도 선택 메뉴 없음. 상단 상시 면책 배너 없음. 출처/한계는 문제은행·해설·문서에서 제공하며 비공식 표시는 사이드바/푸터에 둔다. 실제 저장 실패·손상 경고는 유지한다.
- 메뉴의 독립 세로 스크롤, `100vh` fallback과 `100dvh`, 콘텐츠 높이 보존, 스크롤 전파 제어.

## 시험 설정과 확인 상태

공식 확인 시도: 2026-10-24. Q-Net과 국가법령정보센터 두 HTTPS 요청은 프록시 CONNECT 403으로 실패했다. 다음 값은 일반적으로 알려진 시험 구조를 적용한 **학습용 설정이며 이번 작업에서 공식 자료로 검증 완료하지 못했다.** 정확한 현행 시험은 Q-Net의 해당 연도 시행계획을 확인해야 한다. 법령·교시별 휴식 일정·입실 마감·응시 자격·합격예정자 서류심사는 앱에서 재현하지 않는다.

| 교시 / 시험과목 | 영역 (각 25문항) | 문항 | 시간 | 과락 경계 |
|---|---|---:|---:|---:|
| 1 / 사회복지기초 | 인간행동과 사회환경, 사회복지조사론 | 50 | 50분 | 20개 정답 |
| 2 / 사회복지실천 | 사회복지실천론, 사회복지실천기술론, 지역사회복지론 | 75 | 75분 | 30개 정답 |
| 3 / 사회복지정책과 제도 | 사회복지정책론, 사회복지행정론, 사회복지법제론 | 75 | 75분 | 30개 정답 |

총 200문항·5지선다·200분, 문항별 동일 배점. 전체 60% 이상(120개 이상)이면서 **3개 시험과목 각각 40% 이상**이어야 학습용 합격으로 판정한다. 8개 세부 영역별로 각각 과락을 적용하지 않는다. 점수는 100점 환산으로 표시하며 판정은 반올림 전 비율을 사용한다. 미응답은 오답이다. 교시 간 휴식은 타이머에 포함하지 않는다. 시험 전체의 문항은 각 영역 안에서 무작위 순서이며 서로 다른 교시를 섞지 않는다.

설정 위치: `src/profile.ts`. 문제 데이터: `src/data/questions-main.json`.

확인하려던 공식 자료(접근 실패이며 읽은 자료로 인용하지 않음):
- https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=9751
- https://www.law.go.kr/법령/사회복지사업법시행령

## 실제 문제은행과 이용 조건

| 영역 | 내부 검토 등록 문항 |
|---|---:|
| 인간행동과 사회환경 | 25 |
| 사회복지조사론 | 25 |
| 사회복지실천론 | 25 |
| 사회복지실천기술론 | 25 |
| 지역사회복지론 | 25 |
| 사회복지정책론 | 25 |
| 사회복지행정론 | 25 |
| 사회복지법제론 | 25 |
| 합계 | **200** |

원문 기출 **0**, 복원 **0**, 자체 제작 **200**, 숫자 조건 변형 **0**(변형 family 0), 검증 대기 기본 문항 **0**. 목표 1,000개 대비 **800개 부족**. 개인 로컬 등록분은 이 수에 포함하지 않는다. 법제 영역은 일반적인 권리·절차 원칙 중심이며, 확인하지 않은 현행법 조문 번호나 급여 금액·기한을 출제하지 않았다.

- AI의 일반 지식을 바탕으로 직접 작성한 원고다. 출처·회차·연도·외부 검수자를 만들지 않았다. 모든 기출 연도와 회차는 null이다.
- 문항·정답·오답 보기·해설의 내부 논리와 ID·정규화 본문/보기 중복을 검토했다. 보기를 재배치한 중복도 제거한다. 관련 개념이 과목을 걸쳐 반복될 수 있으며, 200문항을 서로 다른 200개 이론이나 전문가 검수 결과로 해석하면 안 된다.
- 학습에 쓰이는 `reviewed`는 **내부 검토**를 뜻한다. 전문가 검수·공식 출제기준 대조·현행 조문 대조 완료를 뜻하지 않는다. 자동 스키마 검사만으로 해설 정확성이 입증된다고 주장하지 않는다.
- 자체 제작 원고의 이용 조건은 **CC BY 4.0**. 표시: `Certified-Social-Worker-Grade1-CBT contributors`, 저장소 링크와 변경 사항 표기. 코드 MIT 라이선스와 구분한다.
- 문항의 저장소 링크는 작성 원고의 위치이며 외부 정답 증빙이 아니다. 제3자 문제를 추가할 경우 그 원문과 재배포 권한을 별도로 확인해야 한다. 공개 웹페이지라는 이유만으로 복제를 허용하지 않는다.
- 신뢰할 수 있는 추가 원자료와 독립적인 내용 검토를 확보하지 못한 상태에서 수량만 늘려 검수 완료로 표시하지 않았다. 공식 규칙 대조와 문항 확충은 남은 작업이다.

`python3 scripts/author_bank.py`로 결정적 원고에서 동일 JSON/양식을 재생성한다. 숫자 변형 생성은 없다. 재생성은 기존 학습 ID를 유지해야 하며 임의의 기출 메타데이터를 추가하지 않는다.

## 로컬 개발과 검증

Node 24.19.0 (`.node-version`), npm 11.9.0. 저장소 루트에서:

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

현재 클라우드의 기존 Chromium은 다음으로 사용했다(새 CI는 위의 Playwright Chromium 설치 경로 사용):

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

검증 범위·실제 결과·배포 중단 사유는 [검증 기록](docs/verification.md)에 정리했다. 실기기 검증과 새 클라우드 스냅샷의 복원 검증은 하지 않았다.

## 저장·백업

`social-worker-grade1-cbt:v1` namespace로 localStorage에 저장한다. 다른 자격증과 키를 공유하지 않는다. 최근 응답 5,000개와 시험 30회까지 보관하며 통계도 이 범위 기준이다. 새로고침 전 저장 실패 시 경고하며 손상 원본은 자동으로 덮어쓰지 않는다. JSON 학습 기록 백업과 손상 원본 백업은 제공하지만 **학습 기록 백업 복원 UI는 없다**. 확인창을 거치는 초기화는 개인 기록·로컬 문항만 삭제하고 기본 200문항은 유지한다. JSON/CSV 문항 가져오기는 해당 브라우저에만 저장되고 GitHub 공용 은행에 자동 게시되지 않는다. iframe·시크릿 모드 등 저장 제한과 iframe 포커스는 브라우저에 따라 다르며 이 작업에서 iframe 통합 검증은 하지 않았다.

## GitHub 반영과 배포

`.github/workflows/pages.yml`: main push → 단위 검사·빌드·PC/모바일 검사 성공 → Pages 자동 배포. PR은 검증만 한다. deploy는 validate에 의존하며 `pages: write`, `id-token: write`를 deploy job에 한정한다. 자동 재시도는 없고, push 실행이 있으면 수동 실행을 중복 시작하지 않는다.

이번 배포 사전 확인의 **첫 요청**인 GitHub 저장소 API 조회가 프록시 `CONNECT tunnel failed, response 403`으로 차단됐다. GH_TOKEN은 존재하지만 값은 출력하지 않았고, 부재나 권한 문제로 단정하지 않았다. API 응답을 얻지 못했으므로 Pages Source·관리 권한·기존 게시 상태는 미확인이다.

사용자 지시에 따라 이후 배포 확인/실행을 재시도하지 않았다. **main 푸시, workflow 실행·재실행, 대체 배포 모두 하지 않았다.** 구현은 자동 배포 대상이 아닌 `codex/social-worker-cbt` 브랜치에 보존한다. CI/Pages 성공 및 공개 화면 확인은 주장하지 않는다. 다른 프로젝트도 수정·재배포하지 않았다.
